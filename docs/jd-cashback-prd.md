## 1. 产品概述

### 1.1 产品定位

京东返利小程序是一个基于微信小程序的CPS佣金返利平台，用户可以通过粘贴京东商品链接获取推广返利，平台将京东实际返利的20%返还给用户，帮助用户在京东购物时省钱。

### 1.2 业务目标

- 让用户通过京东购物获得返利优惠
- 通过CPS推广赚取佣金收益
- 构建用户分享推广体系，拉新获客
- 提供简单易用的提现流程，提升用户体验

### 1.3 核心价值

- **用户省钱**：京东购物享受额外返利
- **平台获利**：赚取CPS推广佣金差价
- **分享赚钱**：用户分享商品链接可获得佣金

### 4.3 京东链接转换功能（核心功能）

**需求描述：**
用户在首页输入框粘贴京东商品链接，点击转换按钮后：

1. **解析链接**：提取京东商品SKU/商品ID
2. **查询佣金**：调用京东联盟API查询该商品的预估返利金额
3. **计算用户返利**：用户返利 = 京东实际返利金额 × 20%
4. **生成CPS链接**：使用平台推广位生成京东CPS推广链接
5. **展示结果**：给用户展示：
   - 商品名称
   - 商品价格
   - 京东给平台的预估佣金
   - 用户可获得的预估返利金额
   - 生成的推广链接（或一键复制/打开）

**业务规则：**
- 预估返利仅供参考，最终返利金额以京东联盟实际结算为准
- 只有当京东联盟确认订单有效并结算佣金后，用户返利才会真正入账到用户账户

**流程图：**
```
用户粘贴京东链接
    ↓
解析获取商品ID
    ↓
调用京东联盟API查询商品佣金信息
    ↓
计算用户返利金额 = 平台佣金 × 20%
    ↓
生成平台CPS推广链接
    ↓
返回结果给前端展示
    ↓
用户复制推广链接到京东下单
    ↓
京东跟踪订单 → 平台获得佣金 → 用户账户增加返利
```

**后端API需求：**
- `POST /api/jd/parse` - 解析京东链接
  - 请求：`{"originalUrl": "https://item.jd.com/123456.html"}`
  - 响应：
  ```json
  {
    "productId": "123456",
    "productName": "苹果iPhone 15 Pro Max",
    "productImage": "https://...",
    "originalPrice": 9999.00,
    "platformCommission": 100.00,    // 京东给平台的预估佣金
    "userRebate": 20.00,            // 用户可得返利（20%）
    "cpsUrl": "https://union.jd.com/...",  // 最终CPS链接
    "estimated": true               // 是否为预估
  }
  ```

### 4.7 提现功能

**需求描述：**
用户申请提现，管理员后台审核打款。

**业务规则：**
- ✅ 用户**每个月只能申请提现一次**
- ✅ 最低提现金额由平台配置（建议：10元起提）
- ✅ 只有"可提现余额"才能申请提现
- ✅ 用户需要先添加收款银行卡信息
- ✅ 用户提交提现申请后，状态为"待审核"
- ✅ 管理员在后台看到所有待审核申请，手动核对后打款给用户
- ✅ 管理员确认打款后，将申请状态改为"已打款"
- ✅ 打款完成后，扣除用户账户可提现余额

**提现状态流：**
```
待审核 → 审核通过 → 已打款
                 ↓
              审核拒绝（返还金额给用户）
```

**用户端流程：**
1. 用户点击"申请提现"
2. 检查：
   - 本月是否已申请过提现 → 如已申请，提示无法再次申请
   - 可提现余额 ≥ 最低提现金额 → 如不足，提示余额不足
   - 是否已绑定银行卡 → 如未绑定，引导先添加银行卡
3. 用户输入提现金额
4. 用户选择收款银行卡
5. 提交提现申请
6. 展示提现申请记录列表

**后端API需求：**
- `GET /api/withdrawals/check-eligibility` - 检查是否可以申请提现
  - 返回：`{"canApply": true/false, "reason": "xxx", "maxAmount": 100.00}`
- `POST /api/withdrawals/apply` - 提交提现申请
  - 请求：`{"amount": 50.00, "bankCardId": 1}`
- `GET /api/withdrawals/my` - 获取我的提现记录列表

## 6. 京东联盟API集成

### 6.1 需要调用的API

1. **商品信息查询** - 根据SKU查询商品信息和佣金
2. **推广链接生成** - 生成推广短链接
3. **订单查询** - 查询订单状态和结算金额
4. **佣金结算查询** - 查询已结算佣金

### 6.2 配置项（需要在application.properties中添加）

```properties
# 京东联盟配置
jd.union.api-key=你的京东联盟API密钥
jd.union.promotion-id=你的推广位ID
jd.union.app-key=你的AppKey
jd.union.app-secret=你的AppSecret
```

### 6.3 订单同步流程

因为京东订单确认和结算需要一定时间（通常1-30天），需要定时同步订单状态：

1. **定时任务**：每天凌晨同步最近30天的订单状态
2. 当订单状态变为"已结算"且佣金已到账平台：
   - 将订单状态更新为"已返利"
   - 计算用户返利金额（平台佣金 × 20%）
   - 增加用户账户的可提现余额
   - 增加累计总佣金
   - 创建佣金明细记录

## 8. 业务规则汇总

| 规则 | 说明 |
|------|------|
| 用户返利比例 | 用户返利 = 京东实际结算给平台的佣金 × 20% |
| 提现频率 | 用户每个自然月只能申请提现一次 |
| 最低提现金额 | 建议10元起提（可配置） |
| 提现到账 | 管理员手动打款，不是自动到账 |
| 排行榜更新 | 每月1号自动清零重新排行 |
| 广告管理 | 只有启用的广告才会在首页展示 |
| 热门商品 | 只有标记为热门的商品才会在首页展示 |
